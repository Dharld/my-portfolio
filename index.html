TrendSpot

Demo

TrendSpot — AI Marketing Platform

Founded and solo-built an AI marketing platform that turns a company's website into finished, on-brand ads without a designer or agency. The Creative Signal Engine ingests competitor ads from the Meta, Google, and TikTok ad libraries and extracts 22 structured creative signals per ad, using pgvector cosine similarity and cross-platform pattern analysis to rank A/B ad-test strategies before any spend. A multi-agent system on the AWS Strands SDK then produces the creative — a strategist plans, copywriters and art directors work in parallel, and a reviewer checks the output — generating images and video through OpenAI, Gemini, and Veo behind a provider router that fails over automatically when a model is unavailable. Every agent step is recorded with its prompt hash, model ID, and tool allowlist, so any piece of creative can be traced back to the decisions that produced it. The whole system runs on AWS: CDK-defined RDS PostgreSQL with pgvector, Dockerized FastAPI workers and Redis-backed queues on EC2, a Next.js frontend, and a GitHub Actions pipeline that tests every change and ships it on its own.
